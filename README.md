# Apex Solutions – Zahabia Travel & Tourism

M0 foundation for Zahabia Travel & Tourism's air ticketing and tour management platform.

## Run locally

```bash
cp .env.example .env
npm install
npm start
```

Open `http://localhost:3000`, or check `http://localhost:3000/health`.

The health endpoint requires valid MySQL credentials. The M0 placeholder login accepts any non-empty email and password; real auth is an M3 deliverable.
